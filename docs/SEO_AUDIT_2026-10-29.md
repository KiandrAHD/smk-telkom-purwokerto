# Audit teknis SEO — 29 Oktober 2026

## Ruang lingkup dan metode

Target: https://smk-telkom-purwokerto.vercel.app/. React 19, React Router 7, Vite 8, prerender React saat build, filesystem statis dan SPA fallback Vercel. Tidak mengganti arsitektur, URL, desain, konten editorial, atau tracker.

Baseline HTTP produksi: `outputs/seo-inventory-baseline.json`. Sesudah lokal: `outputs/seo-inventory-local.json`. Inventaris mencatat setiap URL, status/final URL (produksi saja), lang, title, description, canonical, robots, heading, tautan internal, alt, dan JSON-LD. Status 200 pada inventaris lokal adalah simulasi pembacaan file, **bukan** pengukuran HTTP. Kedua inventaris memakai ekstraksi parse5 yang sama. Konten feed dapat berubah antara waktu pengukuran.

146 URL sitemap, seluruhnya 200 pada baseline. Kelompok: homepage 1; berita 19; BKK 13; ekstrakurikuler 1; fasilitas 1; galeri 5; jurusan 11; kalender 1; privasi 1; ketentuan SPMB 1; NextTel 1; pengumuman 16; prestasi 23; profil sekolah/guru 50; SPMB 1; STELA 1. Sitemap bukan bukti bahwa Google sudah mengindeks URL.

Chrome headless lokal: 13 route representatif; rendering JavaScript, canonical, graph, kontak sekolah, kesesuaian breadcrumb DOM/schema, query tracking, navigasi SPA, pemulihan halaman error, login noindex, pergantian bahasa, overflow lebar 390/768/1440, konten tanpa JavaScript dan runtime errors. Browser terintegrasi tidak terhubung; Chrome dijalankan dengan Playwright eksternal di direktori sementara, bukan dependency produksi. Belum ada perbandingan screenshot pixel sebelum/sesudah.

## Persetujuan dan rilis

Pengguna memilih branch audit tanpa deployment. `git.deploymentEnabled` dinonaktifkan hanya untuk `seo/technical-audit-2026-10-29`. Tidak merge, deploy CLI, ubah DNS/domain, kirim sitemap, memasang tracker, membuat halaman/Google Business Profile, atau mengubah konten terlihat.

Sebelum rilis:
1. Konfirmasi host utama dan kewenangan identitas; jika ini demo, putuskan apakah seluruh demo seharusnya noindex.
2. Konfirmasi sumber klaim angka, kontak/email, data SPMB, tanggal asli berita, author, foto/alumni, dan penanggung jawab editorial.
3. Hubungkan akses Vercel/GSC bila diperlukan. Gunakan build produksi, bukan build:ci. Pastikan API publik berita/pengumuman/prestasi/BKK/SPMB/events dapat dibaca dari build tanpa service-role key browser.
4. Lakukan review screenshot/keyboard/mobile; audit ini tidak mengklaim pixel regression test selesai.
5. Setelah persetujuan deployment, verifikasi URL bersih Vercel filesystem-first, HTTP, canonical/robots/schema dan header OG. Ulang inventaris HTTP. Pastikan branch lain tetap menggunakan kebijakan deployment sebelumnya.
6. Periksa GSC URL Inspection live dan indexed version, Pages indexing, Sitemaps dan Search performance; submit sitemap hanya setelah izin. Pantau Core Web Vitals lapangan bila tersedia.
7. Untuk konten baru/diubah, rebuild agar snapshot HTML dan sitemap sinkron; jangan memakai lastmod palsu atau sitemap URL belum valid.
8. Rencanakan genuine 404 dan continuity hydration secara terpisah dengan pengujian callback/portal/detail baru.
